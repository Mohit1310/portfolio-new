## Behavior first
Validate loading, error, and empty states before discussing naming or formatting.

## Accessibility next
Check semantic structure, keyboard navigation, and visible focus states.

## Performance and maintainability
Look for unnecessary client components, oversized dependencies, and avoidable re-renders.

### Pre-merge list
- Validate edge states.
- Confirm keyboard and screen-reader basics.
- Check bundle and rendering cost.
- Ensure the code is understandable for the next engineer.
